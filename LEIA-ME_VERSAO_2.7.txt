PÔQUER CHINÊS ONLINE — VERSÃO 2.7 COM CHAT
============================================

Esta é a versão completa do projeto. Não combine com versões anteriores.

CHAT DA SALA
------------
- Funciona na sala de espera, durante a partida e entre rodadas.
- Clique no botão Chat no canto inferior direito.
- Mensagens não lidas aparecem em um contador.
- São mantidas as últimas 100 mensagens enquanto a sala existir.
- Limite de 280 caracteres por mensagem.
- O servidor possui proteção contra envio excessivo de mensagens.
- Bots não enviam mensagens.
- O histórico continua nas revanches realizadas na mesma sala.

ATUALIZAR NO GITHUB
-------------------
1. Extraia este arquivo ZIP.
2. Abra o repositório poker-chines-online no GitHub.
3. Clique em Add file.
4. Clique em Upload files.
5. Arraste TODO o conteúdo extraído:
   - public
   - server.js
   - package.json
   - package-lock.json
   - render.yaml
   - README.md
   - .gitignore
   - LEIA-ME_VERSAO_2.7.txt
6. Não envie o próprio ZIP.
7. Aguarde todos os arquivos carregarem.
8. Em Commit message, escreva:
   Adicionar chat dentro da sala
9. Selecione Commit directly to the main branch.
10. Clique em Commit changes.

RENDER
------
O deploy normalmente começa automaticamente após o commit.

Se não iniciar:
Manual Deploy → Deploy latest commit

Se houver erro de cache:
Manual Deploy → Clear build cache & deploy

Build Command:
corepack enable && corepack prepare yarn@1.22.22 --activate && yarn install --production --non-interactive --network-timeout 600000

Start Command:
node server.js

Root Directory:
deixe vazio

Environment:
NODE_VERSION = 24.17.0
